## Overview

**NeoDesk** is a local and web-deployable Indian stock market terminal and paper trading platform. It integrates with Kotak Neo broker APIs for real-time market data (quotes, historical candles, and option chains) and maintains an isolated, single-user paper trading simulation account with persistent SQLite storage.

## Data Flow

1. **Market Data & Quotes**:
   Client requests `/api/market/quotes` → `server.py` queries `Market.quotes()` → Cache checked → `KotakNeoBroker.quotes()` called (or fallback demo prices) → Returned as normalized JSON.
2. **Order Submission**:
   Client submits `/api/paper/orders` with `request_id` → `server.py` validates request via Pydantic → `PaperAccount.submit()` checks capacity & reservations in SQLite → Fills or queues limit order → Updates `positions` & `account` in paise → Writes audit trail.
3. **Background Limit Order Matcher**:
   FastAPI lifespan starts `match_loop()` → Periodically checks open orders in SQLite → Fetches live quotes → Executes fills when limit condition met.
4. **Catalogue Synchronization**:
   User triggers `/api/instruments/sync` → Background task downloads segmented CSV files from Kotak S3 endpoints → Normalizes and bulk upserts into SQLite `instruments` table.

## Conventions

- **Money Accounting**: All internal currency is calculated and stored in integer paise (`paise = int(round(val * 100))`) to eliminate floating-point drift.
- **Security Headers**: API requests require `X-NeoDesk: 1` and validated `Origin`.
- **Packaging & Delivery**: Standalone single-port mode exports Next.js static files to `frontend/out` and mounts them onto FastAPI.
- **Testing**: Backend verified via `pytest` (`backend/tests/`); frontend verified via `npm run lint` and Next build.
