## Lessons Learned
- Implementing WebSocket integrations efficiently requires careful React state management (e.g. `React.memo` and avoiding synchronous state updates in `useEffect`) to prevent layout thrashing on high-frequency streams.
- The `SFeed` structure from Kotak can be seamlessly mapped to internal trading abstractions.
- Live and Paper state isolation is robustly achievable by abstracting order endpoints to dynamically switch via the client-side `marketStore`.
