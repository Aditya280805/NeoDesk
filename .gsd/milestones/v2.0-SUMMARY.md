# Milestone: v2.0 (Instrument Details, Charting, and Theming)

## Completed: 2026-10-06

## Deliverables
- ✅ Backend API for historical chart data (`/api/market/history`) supporting 1D, 5D, 1M, 1Y, 5Y intervals with caching.
- ✅ Dynamic frontend route for Instrument Details (`/instrument/[id].tsx`) with fundamentals, technical indicators, and responsive layout.
- ✅ Interactive charting integration via `lightweight-charts` with dynamic timeframe switching.
- ✅ Global theme refactor with `next-themes` and CSS variables, providing a blueish-black dark theme and clean light theme.

## Phases Completed
1. Phase 1: Instrument Details Backend & History API — 2026-10-06
2. Phase 2: Instrument Details Frontend Page & Interactive Charting — 2026-10-06
3. Phase 3: Global Theme Refactor (Light/Dark Mode) — 2026-10-06

## Lessons Learned
- Lightweight-charts requires dynamic import in Next.js (`next/dynamic` with `ssr: false`) to avoid server-side `window` undefined errors.
- Using `next-themes` with `attribute="class"` and CSS custom properties prevents hydration mismatches and allows seamless runtime theming.
