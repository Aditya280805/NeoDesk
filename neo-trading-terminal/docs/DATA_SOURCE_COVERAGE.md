# Supported data coverage

Configured source choice: Kotak Neo and optional per-user imports; no additional data provider selected.

| Capability | Source and coverage |
| --- | --- |
| Current holdings, positions, orders, funds | Authenticated individual Kotak session; live dashboard verified |
| Options snapshot and standard Options agent | Authenticated Kotak chain and local configured model; live UI verified |
| Executed fills | Current trading day from trade_report; not historical account performance |
| Technical candles | Bounded broker historical_data; adjustment factors are not established by its documented candle schema |
| Adjusted asset/benchmark/IV histories | Optional validated historical JSON inputs; no automatic authoritative feed configured |
| Historical cash flows | Optional ledger CSV, explicit column/type/date/unit or debit/credit mapping; user-declared coverage |
| Complete account/proposal risk | Requires verified complete inventory, marks, applicable margins and limits; partial scenarios do not certify this |

Missing ledger data does not disable market tools. Uploaded ledger movement totals are not investment returns. Unknown source fields remain unavailable, never zero-filled or generated by a model. No automatic or complete historical-data coverage should be advertised without the corresponding source integration.

Source interfaces verified using Context7 against official SDK docs:
- https://github.com/kotak-neo/kotak-neo-python/blob/main/docs/functions/orders/trade_report.md
- https://github.com/kotak-neo/kotak-neo-python/blob/main/docs/functions/market_data/historical_data.md
- https://github.com/kotak-neo/kotak-neo-python/blob/main/docs/functions/portfolio/margin_required.md

MongoDB and Docker are not runtime prerequisites for this repository's local SQLite/single-worker setup. Public production hosting, backups, data permissions, external CI and data licensing still require deployment-specific validation; local tests are not proof of those gates.
