# Complete the Options Agent Platform — approved specification

User approved implementation on 2026-11-01. This records the approved plan's requirements; Phase 0–2 is the existing baseline.

One Agno agent uses modular deterministic services through private, owner-scoped MCP. Support both owned-stock and hypothetical purchases immediately, NSE individual-stock F&O, risk/liquidity filtering before net-horizon-yield ranking, durable background monitoring with in-app alerts, free model access and separately approved paid market data. Deliver a usable historical importer/backtesting engine with synthetic data even if real historical coverage remains unavailable. No automatic trading, self-modification, paid purchase or deployment.

## Required delivery

1. **Data readiness:** inventory holdings availability, positions/orders/fills, contract identities/lots/expiry, executable quotes/depth/timestamps, margin/account P&L and historical coverage. Record supported/missing/unverified per input with official source references, version-bound field mappings and no inferred semantics. Preserve observation times/provenance/nulls. Verify settlement, delivery, exercise and corporate-action rules before enabling affected live calculations. Provide explicit opt-in local broker/model smoke workflows, sanitized output and quota-unavailable behavior.
2. **Strategies:** pure versioned covered-call/collar calculators for owned and hypothetical stock. Explicit quantity, option legs, basis, expiry, costs. Verify underlying/lot/expiry/available coverage/settlement. Output scenario payoff, breakeven, cashflows, extrema where defined, stock capital separately from broker margin, horizon yield. Owned results show acquisition/current bases. Hypothetical entry uses ask buys/bid sells; missing executable quotes only theoretical and excluded from ranking. Missing costs cannot claim net yield. Eligibility is eligible/ineligible/cannot_assess against explicit user criteria. Immutable user-saved baselines capture assumptions, evidence and policy. Hypothetical is not confirmed position.
3. **Risk/monitoring:** sizing, verified underlying exposure, strategy loss and cashflow-adjusted drawdown with complete supported equity/cashflow history. Explicit confirmed leg associations, no symbol inference; strategy P&L/yield/deviations only with valid fills/costs. Durable SQLite jobs/leases/alerts; opt-in 60-second monitoring, one active job/user, bounded shared broker capacity with interactive priority, no overlap, skip missed ticks after restart, suspend on broker session loss, resume only after reconnection. Deduplicate breach/state-change/recovery events, owner inbox/read/ack. No model call on ticks.
4. **Scanner:** versioned current NSE stock F&O universe; user-triggered resumable/cancellable bounded scans, quota backoff and partial coverage. User capital/horizon/liquidity/spread/downside criteria required. Filter eligibility/freshness/liquidity/risk before candidates. Rank within strategy/horizon/capital basis by descending net yield, narrower spread, supported liquidity, stable ID. Show downside separately, exclusions and reproducible evidence/policy/calculation versions.
5. **Backtesting:** dedicated options engine and validated CSV/Parquet import for contracts/quotes/corporate actions/settlement. Reuse strategy arithmetic, point-in-time information only, costs/slippage/depth/quantity/expiry/settlement, no future fills or silent gaps. Trade ledger/equity/drawdown/exposure/cost/expected-realized outputs and run manifests. Synthetic reference data first; paid historical source assessment does not purchase data.
6. **Evaluation/research:** benchmark each capability for numerical/evidence/factual/completeness/consistency/interpretation/null/abstention behavior. Separate development/held-out sets; explicit sanitized real capture rules. Compare base/prompt/context variants on same benchmark with opt-in live runs. Promotion: all deterministic/auth tests pass, no critical fabrication/unauthorized claims, complete references, no scored regression. Record versions/latency/failures/usage; unknown cost stays null. Fine-tuning feasibility assessment, conditional later experiment, no mandatory paid training.
